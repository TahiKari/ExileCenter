ExileCenter.ArchiveCodec-sources.zip accompanies the DLL and contains the exact
decoder sources, SIMDe headers and notices, adapter, CMake build file and GPL text.
Extract it and build with Visual Studio C++ x64 and CMake:
  cmake -S . -B build -A x64
  cmake --build build --config Release

The writer stores modified chunks without compression. The game reads the same
uncompressed bytes; the patched index and bundle may occupy more disk space.
